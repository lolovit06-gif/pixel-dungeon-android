PIXEL DUNGEON ANDROID v0.2

Прототип top-down pixel dungeon с сенсорным джойстиком и кнопкой ATTACK.
На компьютере также поддерживается движение клавишами WASD/стрелками и атака пробелом.

Сборка APK запускается автоматически при push в main через GitHub Actions.
Откройте вкладку Actions в репозитории, выберите завершившийся запуск Build Android APK и скачайте артефакт PixelDungeon-Android-APK. Внутри архива должен находиться PixelDungeon.apk.

Это ранний прототип, не проверенный на физическом Android-устройстве. Если сборка упадёт, проверьте лог соответствующего шага в Actions.
